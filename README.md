# Slugline — Free Offline Installer

![Category](https://img.shields.io/badge/Screenwriting-blue?style=flat-square)

## About

Slugline is a clean, elegant screenwriting application for macOS and iOS that uses Fountain markup to store scripts as plain text. Write scripts in a distraction-free environment with automatic formatting as you type — scene headings, action lines, and dialogue appear correctly styled without manual formatting. Slugline's plain text foundation ensures your scripts are never locked in a proprietary format.

## Common Problems & Limitations

- **Apple Only** — macOS and iOS only; no Windows version
- **Fountain Learning Curve** — Writers unfamiliar with Fountain markup need brief orientation
- **Production Features** — Limited production-focused features like scheduling and budgeting
- **Collaboration** — Collaborative writing requires third-party version control solutions
